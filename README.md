
# 大学生の不安とスマートフォンの習慣的確認行動の関連

## 問題と目的

大学生の日常生活において、スマートフォンを無意識のうちに繰り返し確認する行動は、もはや珍しいものではなくなっている。SNSの通知確認、メッセージの既読確認、ニュースの閲覧といった行動は、多くの場合、明確な目的意識を伴わず、特定の場面や心理状態を手がかりとして自動的に生起する。心理学ではこのような反応傾向を「習慣（habit）」と呼び、遂行時の低い意識性と高い自動性がその中核的特徴とされている（Verplanken & Orbell, 2003）。Verplanken and Orbell（2003）が開発したSelf-Report Habit Index（SRHI）は、こうした習慣の強さ（習慣強度）を測定する尺度として国際的に用いられており、日本国内でも高見（2023）によって日本語版（SRHI-J）が開発され、内的信頼性および構成概念妥当性が確認されている。

一方で、スマートフォンの過剰使用や依存傾向が、単なる時間的な問題にとどまらず、不安などの心理的健康と結びついている可能性は、これまで繰り返し指摘されてきた。沖田・近藤（2022）は医療系大学生178名を対象とした調査において、スマートフォン依存群は非依存群と比較して心理的ストレス反応が有意に高く、その下位尺度である「抑うつ・不安」も含めすべての下位尺度で依存群の得点が有意に高いことを示した。海外においても、Demirci et al.（2015）は大学生319名を対象とした調査において、高スマートフォン使用群は低使用群と比較して不安得点が高く、Smartphone Addiction Scale得点と不安得点との間に正の相関が認められることを示した。

しかし、これらの先行研究の多くは「依存傾向」や「使用時間」に着目したものである。沖田・近藤（2022）が用いたスマートフォン依存スケール短縮版（Smartphone Addiction Scale-Short Version: SAS-SV）や、Demirci et al.が使用したSmartphone Addiction Scale（SAS）は、日常生活への支障や離脱症状、耐性といった依存の結果として生じる症状を測定するものであり、行動そのものがどれほど自動的・無意識的に生起しているかという自動性の程度、すなわち習慣強度を直接的に測定するものではない。実際、モバイルアプリの利用を対象とした研究では、習慣（Habit）尺度と依存（Addiction）尺度を同時に測定した結果、両者の相関係数は中程度にとどまり（r = .351）、習慣と依存が実証的にも独立性の高い異なる構成概念であることが示されている（Jo & Baek, 2023）。この知見は、習慣強度と不安の関連を、依存研究とは別に検討すべきことを示唆している。

「依存しているかどうか」ではなく「どれだけ無意識に自動化しているか」という観点から、スマートフォンと心の健康の関係を捉え直そうとする点に、本研究の意義がある。そこで本研究では、不安の個人差がスマートフォンの習慣的確認傾向（習慣強度）をどの程度説明するかを、スマートフォン依存傾向の影響を統制した上で検討することを目的とする。具体的には、「特性不安が高い大学生ほど、スマートフォンの習慣的確認傾向が強い」（仮説1）、「特性不安と習慣的確認傾向との関連は、スマートフォン依存傾向の影響を統制してもなお認められる」（仮説2）、および「状態不安の影響を統制してもなお、特性不安は習慣的確認傾向を予測する」（仮説3）という3つの仮説を設定し、これらを検証する。なお、本研究は横断的な相関研究であり、変数間の因果の方向を特定するものではない。以下で用いる独立変数・従属変数という区分は、統計モデル上の役割を指す。

## 方法

### 調査参加者

同一大学に在籍する大学生約100名を対象とした。参加者は学部内の授業や学内掲示等を通じて募集し、調査への参加は任意であり、成績評価等には一切影響しないことを事前に説明した上で実施する。

### 使用尺度

**習慣強度（習慣的確認傾向）** 日本語版自己報告式習慣指標（Self-Report Habit Index Japanese version: SRHI-J）を用いた（高見, 2023）。SRHI-Jは原版であるVerplanken and Orbell（2003）のSRHIを高見（2023）が日本語に翻訳・開発した尺度であり、対象行動の自動性、意識性の欠如、統制欠如などの心理的特性を反映する12項目から構成される。回答は「1: 全くあてはまらない」から「7: とてもあてはまる」までの7段階評定である（高見, 2023）。本研究では、SRHI-Jの教示文における対象行動を「スマートフォンを確認すること」に指定して使用し、得点が高いほど当該行動の習慣強度が高いことを示す。

**不安** 日本語版State-Trait Anxiety Inventory（新版STAI）を用いた。STAIはSpielberger, Gorsuch, and Lushene（1970）によって開発された、一過性の状況反応としての状態不安（State Anxiety）と、比較的安定した性格特性としての特性不安（Trait Anxiety）を分離して測定する自己評定式の不安検査である（清水・今栄, 1981）。日本語版は清水・今栄（1981）によって愛知教育大学の大学生を対象に作成され、原版とほぼ同水準の内的信頼性（α係数.83〜.87）および再検査信頼性、他の不安尺度との併存的妥当性が確認されている。状態不安尺度20項目、特性不安尺度20項目から構成され、「全くあてはまらない」から「非常によくあてはまる」までの4件法で回答を求める（清水・今栄, 1981）。本研究では両下位尺度の得点を算出し、それぞれを不安の指標として分析に用いる。

### 手続き

調査は質問紙法（または同等のオンラインフォーム）により実施する。参加者にはまず研究の趣旨、データの匿名性、回答の任意性、および同意撤回が可能である旨を説明した上で、インフォームド・コンセントを取得する。その後、フェイスシート（学年、性別、年齢等の基本属性）、SRHI-J（対象行動：スマートフォンの確認）、新版STAIの順に回答を求める。回答に要する時間は15〜20分程度と見込まれる。実施にあたっては、教示文中で「不安」という語を直接用いず、質問紙を「自己評定質問紙」として提示するなど、原版の実施手続きに準じた配慮を行う（清水・今栄, 1981）。

### 倫理的配慮

本調査は、所属大学における研究倫理審査の承認を得た上で実施する。参加者に対しては、調査への協力が任意であること、回答内容によって不利益を被らないこと、得られたデータは統計的に処理され個人が特定されない形で扱われること、および同意はいつでも撤回できることを書面または画面上で説明し、同意を得られた者のみを分析対象とする。

### 分析方法

得られたデータについて、まずSRHI-J、新版STAI各下位尺度、およびスマートフォン依存傾向尺度の記述統計量（平均値、標準偏差）とCronbachのα係数による内的整合性を確認する。次に、SRHI-J得点と状態不安・特性不安それぞれの得点との関連について、Pearsonの積率相関係数を算出する（仮説1）。続いて、SRHI-J得点を従属変数、特性不安得点を独立変数とし、スマートフォン依存傾向および性別・学年などの基本属性を統制変数として投入した重回帰分析を行う（仮説2）。仮説3については、SRHI-J得点を従属変数とする階層的重回帰分析を行い、統制変数および状態不安得点を投入した後に特性不安得点を投入して、特性不安による説明率の有意な増分（ΔR²）が認められるかを検討する。なお、状態不安と特性不安は相互に高い相関を示すことが想定されるため、両者を同一の回帰式に投入する場合は多重共線性の程度（VIF等）を確認する。
