
# 大学生の不安とスマートフォンの習慣的確認行動の関連

## 問題と目的

大学生の日常生活において、スマートフォンを無意識のうちに繰り返し確認する行動は、もはや珍しいものではなくなっている。SNSの通知確認、メッセージの既読確認、ニュースの閲覧といった行動は、多くの場合、明確な目的意識を伴わず、特定の場面や心理状態を手がかりとして自動的に生起する。心理学ではこのような反応傾向を「習慣（habit）」と呼び、遂行時の低い意識性と高い自動性がその中核的特徴とされている（Verplanken & Orbell, 2003）。Verplanken and Orbell（2003）が開発したSelf-Report Habit Index（SRHI）は、こうした習慣の強さ（習慣強度）を測定する尺度として国際的に用いられており、日本国内でも高見（2023）によって日本語版（SRHI-J）が開発され、内的信頼性および構成概念妥当性が確認されている。

一方で、スマートフォンの過剰使用や依存傾向が、単なる時間的な問題にとどまらず、不安などの心理的健康と結びついている可能性は、これまで繰り返し指摘されてきた。沖田・近藤（2022）は医療系大学生178名を対象とした調査において、スマートフォン依存群は非依存群と比較して心理的ストレス反応が有意に高く、その下位尺度である「抑うつ・不安」も含めすべての下位尺度で依存群の得点が有意に高いことを示した。海外においても、Demirci et al.（2015）は大学生319名を対象とした調査において、高スマートフォン使用群は低使用群と比較して不安得点が高く、Smartphone Addiction Scale得点と不安得点との間に正の相関が認められることを示した。

しかし、これらの先行研究の多くは「依存傾向」や「使用時間」に着目したものである。沖田・近藤（2022）が用いたスマートフォン依存スケール短縮版（Smartphone Addiction Scale-Short Version: SAS-SV）や、Demirci et al.が使用したSmartphone Addiction Scale（SAS）は、日常生活への支障や離脱症状、耐性といった依存の結果として生じる症状を測定するものであり、行動そのものがどれほど自動的・無意識的に生起しているかという自動性の程度、すなわち習慣強度を直接的に測定するものではない。実際、モバイルアプリの利用を対象とした研究では、習慣（Habit）尺度と依存（Addiction）尺度を同時に測定した結果、両者の相関係数は中程度にとどまり（r = .351）、習慣と依存が実証的にも独立性の高い異なる構成概念であることが示されている（Jo & Baek, 2023）。この知見は、習慣強度と不安の関連を、依存研究とは別に検討すべきことを示唆している。

「依存しているかどうか」ではなく「どれだけ無意識に自動化しているか」という観点から、スマートフォンと心の健康の関係を捉え直そうとする点に、本研究の意義がある。そこで本研究では、不安の個人差がスマートフォンの習慣的確認傾向（習慣強度）をどの程度説明するかを、スマートフォン依存傾向の影響を統制した上で検討することを目的とする。具体的には、「特性不安が高い大学生ほど、スマートフォンの習慣的確認傾向が強い」（仮説1）、「特性不安と習慣的確認傾向との関連は、スマートフォン依存傾向の影響を統制してもなお認められる」（仮説2）、および「状態不安の影響を統制してもなお、特性不安は習慣的確認傾向を予測する」（仮説3）という3つの仮説を設定し、これらを検証する。なお、本研究は横断的な相関研究であり、変数間の因果の方向を特定するものではない。以下で用いる独立変数・従属変数という区分は、統計モデル上の役割を指す。
