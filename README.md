
# 大学生のスマートフォン習慣的確認行動と不安の関連

## 問題と目的

大学生の日常生活において、スマートフォンを無意識のうちに繰り返し確認する行動は、もはや珍しいものではなくなっている。SNSの通知確認、メッセージの既読確認、ニュースの閲覧といった行動は、多くの場合、明確な目的意識を伴わず、特定の場面や心理状態を手がかりとして自動的に生起する。心理学ではこのような反応傾向を「習慣（habit）」と呼び、遂行時の低い意識性と高い自動性がその中核的特徴とされている。Verplanken and Orbell（2003）が開発したSelf-Report Habit Index（SRHI）は、こうした習慣の強さ（習慣強度）を測定する尺度として国際的に用いられており、日本国内でも高見（2023）によって日本語版（SRHI-J）が開発され、内的信頼性および構成概念妥当性が確認されている。

一方で、スマートフォンの過剰使用や依存傾向が、単なる時間的な問題にとどまらず、不安などの心理的健康と結びついている可能性は、これまで繰り返し指摘されてきた。Matar Boumosleh and Jaalouk（2017）はレバノンの大学生を対象とした横断研究において、不安（anxiety）および抑うつがスマートフォン依存傾向を独立に予測することを示した。国内でも、片山（2016）は大学生のインターネット依存傾向が高い群ほど不安感・抑うつ感・イライラ感が強いことを報告しており、スマートフォン依存傾向の高い大学生ほど不安や抑うつなどの心理的不調を抱えやすいことが縦断的検討でも示唆されている。しかし、これらの先行研究の多くは「依存傾向」や「使用時間」といった量的側面に着目したものであり、確認行動そのものがどの程度自動化・習慣化しているかという「習慣強度」の観点から検討した研究は少ない。

この点を検討する意義は、スマートフォン確認行動が単なる頻度の問題ではなく、意識的な制御を経ずに自動的に生起する傾向である点にある。習慣強度が高いほど、確認行動は状況の手がかりに強く結びつき、自分の意志で止めたり抑えたりすることが難しくなっていると考えられる。確認しても・しなくても落ち着かない、という状態が慢性化していれば、それが日常的な不安の高さにつながっていても不思議ではない。つまり「依存しているかどうか」ではなく「どれだけ無意識に自動化しているか」という観点から、スマートフォンと心の健康の関係を捉え直そうとする点に、本研究の意義がある。そこで本研究では、スマートフォンの習慣的確認傾向（習慣強度）と不安の程度との関連を検討することを目的とし、「習慣的にスマートフォンを確認する傾向が強い大学生ほど、不安の程度が高い」という仮説を設定し、これを検証する。

## 方法

### 調査参加者

同一大学に在籍する大学生約100名を対象とした。参加者は学部内の授業や学内掲示等を通じて募集し、調査への参加は任意であり、成績評価等には一切影響しないことを事前に説明した上で実施する。

### 使用尺度

習慣強度（習慣的確認傾向） 日本語版自己報告式習慣指標（Self-Report Habit Index Japanese version: SRHI-J）を用いた。SRHI-Jは原版であるVerplanken and Orbell（2003）のSRHIを高見（2023）が日本語に翻訳・開発した尺度であり、対象行動の自動性、無意識性、反復性、自己同一性といった習慣の心理的特性を反映する12項目から構成される。回答は「1: 全くあてはまらない」から「7: とてもあてはまる」までの7段階評定である。本研究では、SRHI-Jの教示文における対象行動を「スマートフォンを確認すること」に指定して使用し、得点が高いほど当該行動の習慣強度が高いことを示す。

不安 日本語版State-Trait Anxiety Inventory（新版STAI）を用いた。STAIはSpielberger, Gorsuch, and Lushene（1970）によって開発された、一過性の状況反応としての状態不安（State Anxiety）と、比較的安定した性格特性としての特性不安（Trait Anxiety）を分離して測定する自己評定式の不安検査である。日本語版は清水・今栄（1981）によって愛知教育大学の大学生を対象に作成され、原版とほぼ同水準の内的信頼性（α係数.83〜.87）および再検査信頼性、他の不安尺度との併存的妥当性が確認されている。現在使用されている新版STAI（STAI-JYZ）は、原著者スピルバーガーを共同研究者として英語版STAI-Yの項目を翻訳するとともに日本の文化的要因を考慮した項目を加えて標準化されたものであり、2021年10月に判定基準が再標準化されている。状態不安尺度20項目、特性不安尺度20項目から構成され、「全くあてはまらない」から「非常によくあてはまる」までの4件法で回答を求める。本研究では両下位尺度の得点を算出し、それぞれを不安の指標として分析に用いる。

### 手続き

調査は質問紙法（または同等のオンラインフォーム）により実施する。参加者にはまず研究の趣旨、データの匿名性、回答の任意性、および同意撤回が可能である旨を説明した上で、インフォームド・コンセントを取得する。その後、フェイスシート（学年、性別、年齢等の基本属性）、SRHI-J（対象行動：スマートフォンの確認）、新版STAIの順に回答を求める。回答に要する時間は15〜20分程度と見込まれる。実施にあたっては、教示文中で「不安」という語を直接用いず、質問紙を「自己評定質問紙」として提示するなど、原版の実施手続きに準じた配慮を行う。

### 倫理的配慮

本調査は、所属大学における研究倫理審査の承認を得た上で実施する。参加者に対しては、調査への協力が任意であること、回答内容によって不利益を被らないこと、得られたデータは統計的に処理され個人が特定されない形で扱われること、および同意はいつでも撤回できることを書面または画面上で説明し、同意を得られた者のみを分析対象とする。

### 分析方法

得られたデータについて、まずSRHI-Jおよび新版STAI各下位尺度の記述統計量（平均値、標準偏差）とCronbachのα係数による内的整合性を確認する。次に、SRHI-J得点と状態不安・特性不安それぞれの得点との関連について、Pearsonの積率相関係数を算出する。加えて、性別や学年などの基本属性を統制変数として投入した重回帰分析を行い、習慣的確認傾向（SRHI-J得点）が不安得点を予測するかどうかを検討する。
